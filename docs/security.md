# 隐私与安全边界

1. 本仓库只用于本人有权管理的终端和网络接口。账号、端口、硬件与学校侧策略需要现场确认；不承诺绕过设备数或速率限制。
2. 采集输出仅允许 `seq/elapsed_ms/direction/wire_length/eapol_version/eapol_type/eapol_body_length/eap_code/eap_id/eap_length/eap_type`。拒绝额外键，不输出 MAC、Identity、challenge、response、TLS正文或服务器通知文本。
3. Windows 内存前缀最多32字节，Linux最多23字节；没有PCAP写入路径。Windows方向为unknown，Linux接收限定说明必须保留。
4. Npcap驱动和认证客户端分别使用官方来源。防护保持开启；不要为排障全局重置、关防火墙或卸载驱动。
5. 凭据仅在本机输入，实际配置保存在设备受限目录。口令、SSH私钥、私人SSID、原厂备份和真实采集记录都不应提交。
6. 本仓库没有设置账号、重拨、续租、改网卡、刷机或清故障锁的入口。准备与构建脚本只操作本地公开源码。
7. `.gitignore` 是辅助措施，发布前仍需审查内容。不要把删掉文件后的 Git 历史当作已撤回密钥；此仓库初始发布不携带现场历史。

需要报告缺陷时，请提供版本、平台、固定错误类别及合成复现，不附真实凭据、PCAP或原始客户端日志。本仓库的测试应保持离线，不以真实校园账号作为自动化测试数据。
